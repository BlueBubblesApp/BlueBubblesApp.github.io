<p>Still unsure which version is right for you? Here's a short summary:</p>
<ul>
    <li><p>In general, macOS Ventura is the recommended / best version of macOS for BlueBubbles.</p></li>
    <li><p>Need to save some cash? Go for any OS X machine. You'll miss out on the newer iMessage features, but there's usually 2009 Mac Minis on Ebay for $50-$100 that can be patched to run High Sierra, which works just fine for BlueBubbles.</p></li>
</ul>
