question: "Ngrok keeps disconnecting and/or my URL is not updating, what's going on?"
category: issues
order: 2
---
<p>There are a couple of different things you can try:</p>
<ol>
    <li><p>Register for a free account at <a href="https://ngrok.com" rel="noopener">ngrok</a>. After registering, you can find your account's Auth Token in their portal. Copy and paste that auth token into the token field within the BlueBubbles macOS Server settings. Copy and paste using CMD + V. Finally restart the server app and/or the Mac itself.</p></li>
    <li><p>Verify you do not have a VPN, Proxy, or Custom DNS blocking Ngrok (this is common on school or work networks)</p></li>
    <li><p>Try to connect to your server using the manual server URL/password entry</p></li>
    <li><p>Please make sure your phone time is set automatically rather than manually. We've noticed this can cause connection issues sometimes.</p></li>
</ol>
<p>If all else fails, we highly recommend looking into port forwarding as that will have the greatest reliability.</p>
