question: "When I send a message, it sends twice and the first one fails. What is the issue?"
category: issues
order: 0
---
<p>We aren't 100% sure why this issue happens, however, a simple reboot of the Mac usually fixes the issue. Also, signing up on ngrok's website may help the issue. Do the following:</p>
<p>Register for a free account at <a href="https://ngrok.com" rel="noopener">ngrok</a>. After registering, you can find your account's Auth Token in their portal. Copy and paste that auth token into the token field within the BlueBubbles macOS Server settings. Copy and paste using CMD + V. Finally restart the server app and/or the Mac itself.</p>
